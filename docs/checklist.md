# 개발 체크리스트

마일스톤 정의·완료 기준(verify)의 SoT는 [spec.md](./spec.md) §9. 여기는 **진행 상태만** 기록한다.

**작성 형식 (엄수)**: 체크 항목 + 완료 시 한 줄 근거만. `[ ]` 미착수 / `[~]` 진행 중 / `[x]` 완료.
날짜별 진행 블록·산출물 표를 만들지 않는다 — 이력=git log, 결정 이유=ADR, AI 활용 과정=AI_USAGE.
