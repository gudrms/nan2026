# 캐릭터 emotion별 이미지 생성 프롬프트

기획이 제작한 idle/talk 2상태(`src/assets/characters/`) 위에, LLM이 뱉는 emotion 4종(`neutral`·`joy`·`anger`·`surprise`)에 맞춰
표정이 바뀌는 이미지를 추가하려 할 때 쓰는 참고 프롬프트다. 지금은 emotion을 이모지 오버레이로 대신하고 있고(ADR-003 D1),
이 이미지가 도착하면 `src/components/Character.tsx`의 `ART` 매핑에 `emotion` 축을 추가해 교체한다.

**기준 이미지**: `src/assets/characters/group.png` (4인 라인업) — 새 이미지의 스타일 기준으로 반드시 함께 첨부해서 생성한다.
같은 캐릭터 시트 안에서 일관성을 유지하려면 한 번에 "4인 × 1감정" 세트로 생성하는 편이 낫다.

## 공통 스타일 지침 (모든 프롬프트 앞에 붙인다)

```
귀여운 플랫 카툰 스타일, 두꺼운 검은 윤곽선, 파스텔 색감, 심플한 원형 몸체.
캐릭터: 호랑이(주황·검은 줄무늬), 여우(주황·흰 배), 까치(검은 몸통·흰 배·파란 날개), 한복 입은 소년(도령).
배경 투명 또는 단색. 정면 응시, 서 있는 자세, 몸통 비율·색상은 첨부한 기준 이미지(group.png)와 동일하게 유지.
```

## emotion별 프롬프트

### joy (기쁨) — 잡기 성공·완주·역전 등 좋은 일

```
[공통 스타일 지침]
표정: 눈이 초승달 모양으로 웃음, 입은 크게 벌려 활짝 웃는 표정, 양 볼에 홍조.
포즈: 팔을 살짝 들어 올리거나 통통 뛰는 듯한 역동적인 느낌.
```

### anger (분노) — 잡힘·역전당함 등 나쁜 일

```
[공통 스타일 지침]
표정: 눈썹을 치켜올려 팔(八)자로 찌푸림, 눈은 가늘게 뜨거나 세모 모양, 입은 꾹 다물거나 삐죽.
포즈: 팔짱을 끼거나 주먹을 살짝 쥔 모습. 볼에 홍조 대신 약간 붉은 기.
```

### surprise (놀람) — 예상 밖 전개 (모/윷, 급습 등)

```
[공통 스타일 지침]
표정: 눈을 동그랗게 크게 뜸(흰자 강조), 입은 작은 O자 모양으로 벌림, 눈썹은 위로 살짝 올라감.
포즈: 몸을 살짝 뒤로 젖히거나 손을 뺨/입 근처로 드는 깜짝 놀란 자세.
```

### neutral (기본) — 이미 있는 idle 이미지 그대로 사용, 신규 생성 불필요

## 산출물 규격

- 파일명 규칙: `{character}-{emotion}.png` (예: `tiger-joy.png`), 발화 버전은 `{character}-{emotion}-talk.gif`
- idle 이미지와 동일 캔버스 크기·여백 비율 (겹쳐도 위치가 안 튀도록)
- 배경 투명 PNG 권장 (현재 idle/talk 에셋과 동일 조건)
- 완성되면 `src/assets/characters/`에 추가하고 `docs/AI_USAGE.md` 출처 표에 제작 도구·프롬프트를 기록한 뒤, `Character.tsx`의 `ART` 테이블을 emotion 축으로 확장한다.
