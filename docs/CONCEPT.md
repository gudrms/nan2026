## 2. 컨셉 키워드

**"민화 속 동물들의 설날 윷놀이 대결"**

- **까치호랑이 (호작도)**: 한국 민화의 가장 유명한 모티프. 어수룩하지만 허세 가득한 호랑이와 영리한 까치의 대비 — 게임의 팀 구도와 캐릭터 성격의 원천
- **설날 마당**: 윷놀이가 벌어지는 무대. 명절의 왁자지껄한 분위기
- **입담 대결**: 윷놀이의 진짜 재미는 말싸움. 잡고 잡히는 순간마다 터지는 도발과 환호를 AI가 실시간 생성

## 3. 배경 이야기 (짧은 세계관)

> 설날 아침, 민화 병풍 속 동물들이 마당으로 튀어나와 윷판을 폈다.
> 허세 대장 호랑이가 외친다. "이 몸을 이기면 병풍 속 최고 명당을 내주지!"
> 영리한 까치가 당신 어깨에 내려앉는다. "저 허풍쟁이, 우리가 혼내주자. 내가 도와줄게!"

스토리는 이 3줄이 전부다. 게임 시작 화면에서 짧게 보여주고 바로 플레이로 진입한다.

## 4. 캐릭터 (4인)

### 우리 팀 (파랑)

| | 플레이어 "도령" | 까치 "까비" (아군 AI) |
|---|---|---|
| 역할 | 윷을 던지고 말을 옮기는 주인공 (한복 입은 도령) | 조언자 + 응원단장 |
| 성격 | — | 영리하고 싹싹함. 플레이어를 "대장"이라 부름 |
| 말투 | — | 밝고 빠른 존댓말 반말 혼용. "대장, 지금 업고 가는 게 이득이에요!" |
| 대사 역할 | — | 좋은 수 훈수, 잡혔을 때 분해하기, 역전 시 환호 |
| TTS 보이스 | — | 높고 경쾌한 톤 |

### 상대 팀 (주황)

| | 호랑이 "범이" (적 AI 리더) | 여우 "여울" (적 AI 참모) |
|---|---|---|
| 역할 | 상대 팀 리더, 메인 도발꾼 | 상대 팀 두뇌, 얄미운 계산가 |
| 성격 | 허세 가득, 목소리 크고 단순함. 지고 있어도 큰소리 | 침착하고 능글맞음. 확률과 훈수로 약올림 |
| 말투 | 호탕한 반말. "어흥! 그 말은 이 몸이 접수한다!" | 나긋한 존댓말. "어머, 거기 두시면… 제가 잡아먹겠는데요?" |
| 대사 역할 | 잡았을 때 포효·도발, 잡혔을 때 발끈 | 수 싸움 코멘트, 플레이어 실수 지적 |
| TTS 보이스 | 낮고 굵은 톤 | 중간 톤, 느긋한 억양 |

> 이름 변경 이력: 깍이→까비, 범발톱→범이, 꼬리아홉→여울 (ADR-003, 2026-07-30)

> 캐릭터 3인의 성격·말투 정의는 그대로 LLM 시스템 프롬프트의 페르소나 사양이 된다. (컨셉 문서 = 프롬프트 원본)

## 5. 게임 플레이

### 5.1 기본 룰 (표준 윷놀이 기반)

- **말판**: 전통 29자리 윷판 (외곽 20 + 대각선 지름길 + 중앙 "방")
- **말**: 팀당 4개. 모든 말이 먼저 완주하는 팀 승리
- **던지기**: 윷가락 4개 → 도(1)/개(2)/걸(3)/윷(4)/모(5). 윷·모는 한 번 더
- **잡기**: 상대 말이 있는 칸에 도착하면 잡음 → 상대 말은 출발점으로, 잡은 팀 한 번 더
- **업기**: 같은 팀 말이 있는 칸에 도착하면 업어서 함께 이동
- **지름길**: 모서리 칸(5, 10)에 정확히 서면 대각선 진입 가능

### 5.2 MVP 스코프 조정

| 포함 | 제외 (후순위) |
|---|---|
| 외곽 경로 + 잡기 + 업기 + 윷·모 추가 던지기 | 빽도 |
| 지름길 (구현 부담 낮으면 포함, 아니면 v2) | 말 선택 시간제한 |
| 팀당 말 4개 → 데모 템포 위해 **2~3개로 축소 검토** | 온라인 대전, 랭킹 |

### 5.3 턴 흐름

```
플레이어 턴: 클릭으로 윷 던지기 → 결과 연출 → 이동할 말 선택(탭/클릭)
             └ 이때 까비가 상황 보고 훈수 (LLM)
아군 턴(까비): 판단 AI가 자동 결정 → 선택 이유를 대사로 설명
적 턴 ×2:     판단 AI가 자동 결정 → 상황별 도발/코멘트
```

- 조작은 **클릭 2회 이내** (던지기 1클릭 + 말 선택 1클릭)로 유지
- AI 턴은 자동 진행하되 연출 1~2초로 템포 유지

### 5.4 승리/종료 조건

- 한 팀의 모든 말 완주 시 즉시 종료 → 결과 화면 (승패 + 캐릭터들의 마무리 대사)

## 6. AI 시스템 (게임의 핵심 셀링 포인트)

### 6.1 2-레이어 구조

```
[판단 AI] 룰 기반 휴리스틱 (로컬, 즉시)
  ├─ 어떤 말을 움직일까: 잡기 가능 > 잡힐 위험 회피 > 업기 > 전진
  └─ 게임 진행을 절대 블로킹하지 않음
[성격 AI] LLM + TTS (비동기)
  ├─ 게임 상황(누가 뭘 했나) + 캐릭터 페르소나 → 대사 생성
  └─ 실패/지연 시 프리셋 대사로 폴백 → 게임은 항상 정상 진행
```

### 6.2 대사 발생 트리거 (이벤트 기반, 매 턴 아님)

| 이벤트 | 말하는 캐릭터 | 예시 상황 |
|---|---|---|
| 잡기 발생 | 잡은 쪽 환호 + 잡힌 쪽 반응 | 범이가 도령 말을 잡음 → 범이 도발, 까비 분개 |
| 업기 | 해당 팀 | "든든하게 업고 갑니다!" |
| 윷/모 | 던진 팀 + (가끔) 상대 팀 견제 | 도령이 모 → 까비 환호, 여울 경계 |
| 완주 | 해당 팀 | 첫 완주 시 |
| 역전 (선두 교체) | 양 팀 | 게임 후반 긴장감 연출 |
| 게임 시작/종료 | 전원 | 인사, 승리 소감/패배 억울함 |
| 플레이어 장고 (선택 5초+) | 까비 | 훈수 발동 |

- 한 이벤트당 대사 1~2개로 제한 (템포 + API 비용 관리)
- 프롬프트에 현재 판세 요약(말 위치, 점수 차)을 포함해 **상황에 맞는** 대사 생성

### 6.3 TTS

- 캐릭터별 고정 보이스 3종 (까비=경쾌/높음, 범이=굵고 낮음, 여울=나긋함)
- 대사 생성 → 음성 변환 → 말풍선 표시와 동시 재생
- 말할 때 캐릭터 입/몸 애니메이션 연동 (SVG + CSS)
- 음소거 토글 제공

### 6.4 인프라

- 브라우저 → Vercel 서버리스 프록시(`/api/dialogue`, `/api/tts`) → OpenAI API
- API 키는 서버 측 환경변수로만 보관. 요청 레이트 제한

## 7. 화면 구성

### 7.1 시작 화면
- 타이틀 + 민화풍 캐릭터 4인 일러스트
- 배경 이야기 3줄 → [윷놀이 시작] 버튼
- 음소거 토글

### 7.2 게임 화면 (메인)
```
┌─────────────────────────────────┐
│ [적팀 정보]              [우리팀 정보] │  ← 남은 말/완주 수
│                                 │
│         [ 윷판 (중앙) ]           │  ← 화면의 60%+
│                                 │
│ [범이] [여울]   [까비] [도령] │  ← 캐릭터 스탠딩 + 말풍선
│         [윷 던지기 버튼]           │
└─────────────────────────────────┘
```
- 캐릭터는 판 좌우(적/아군)에 배치, 말할 때 말풍선 + 입 애니메이션
- 현재 턴 캐릭터 하이라이트
- 윷 던지기: 버튼 클릭 → 윷가락 4개가 던져지는 애니메이션 → 결과 표시

### 7.3 결과 화면
- 승/패 연출 + 4인 캐릭터의 마무리 대사 (LLM 생성)
- [한 판 더] 버튼

## 8. 아트 디렉션

- **스타일**: 한국 민화(호작도) 모티프 × 모던 플랫 일러스트 — 전통 소재를 현대적 감각으로
- **제작 방식**: 캐릭터는 기획 자체 제작 이미지(idle PNG + talk GIF — ADR-003), 그 외(윷판·말·이펙트)는 전량 코드 기반 (SVG + CSS 애니메이션). 타인 저작물 에셋 0개
- **컬러 방향**: 한지 배경(따뜻한 미색) + 오방색 포인트 (팀 컬러: 우리팀 청, 상대팀 주황·적)
- **캐릭터**: 귀여운 플랫 일러스트 4인 (범이·여울·까비·도령). 기본=idle, 발화 중=talk GIF, 감정(기본/기쁨/분노/놀람)은 CSS 오버레이 — emotion별 이미지 4종은 추가 제작 예정
- **윷판**: 전통 윷판 도형을 기하학적으로 재해석. 칸은 명확한 원형 노드, 현재 이동 가능 위치 하이라이트
- **폰트**: 무료 한글 폰트 (라이선스 확인된 것만, 예: 프리텐다드/기타 OFL 폰트)

## 9. 사운드

- **TTS 음성**: 캐릭터 대사 (핵심)
- **효과음**: 윷 던지기, 말 이동, 잡기, 완주 — 무료(CC0) 효과음 또는 Web Audio 합성음
- **배경음**: 후순위. 넣는다면 국악풍 무료 음원 (출처 명시)

## 10. 데모 영상 시나리오 (30~60초, 제출물 2 대비)

| 구간 | 장면 |
|---|---|
| 0~5초 | 타이틀 화면 → 게임 시작 |
| 5~15초 | 윷 던지기 연출 + 말 이동. 까비의 훈수 (음성) |
| 15~30초 | **범이가 도령 말을 잡는 장면** — 도발 대사 + 까비 분개 (감정 교환 하이라이트) |
| 30~45초 | 플레이어의 역전 잡기 + 모! 연속 턴 → 팀 환호 |
| 45~60초 | 완주 → 승리 화면, 캐릭터들 마무리 대사 |

> 개발 중에도 이 시나리오가 실제로 연출 가능한지를 기준으로 기능 우선순위 판단

## 11. 제작 범위 요약

### MVP (제출 필수)
1. 윷놀이 코어 룰 (던지기·이동·잡기·업기·완주)
2. 판단 AI (아군 1 + 적 2 자동 플레이)
3. LLM 대사 생성 + 캐릭터별 TTS 재생 + 폴백
4. 화면 3종 + SVG 캐릭터 4인 (표정·입 애니메이션)
5. Vercel 배포 + 공개 GitHub 저장소

### 후순위 (시간 여유 시)
- 지름길·빽도 완전 룰
- STT 음성 명령 ("윷 던져!")
- 배경음, 판세 실황 중계 모드
- 난이도 선택
