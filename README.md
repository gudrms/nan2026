# 윷놀이: 까치호랑이 한판

> 말하는 AI 동물 친구와 한 팀이 되어, 도발하는 AI 호랑이 팀을 윷놀이로 꺾는 **2 vs 2 전통 보드게임**

게임 속 AI 3인이 LLM으로 실시간 생성된 대사를 각자 다른 목소리(TTS)로 말하며 플레이어와 상호작용하는 것이 핵심 차별점이다.

| | |
|---|---|
| 🎮 **플레이** | *(배포 URL — 제출 시 기입)* |
| 🎬 **플레이 영상** | *(YouTube 링크 — 제출 시 기입)* |
| 장르 / 플랫폼 | 턴제 보드게임 / 웹 브라우저 (데스크톱·모바일 반응형) |
| 플레이 인원 / 타임 | 1인 (플레이어+아군 AI vs 적 AI 2) / 한 판 5~10분 |

## 게임 소개

> 설날 아침, 민화 병풍 속 동물들이 마당으로 튀어나와 윷판을 폈다.
> 허세 대장 호랑이가 외친다. "이 몸을 이기면 병풍 속 최고 명당을 내주지!"
> 영리한 까치가 당신 어깨에 내려앉는다. "저 허풍쟁이, 우리가 혼내주자!"

한국 민화 **까치호랑이(호작도)** 모티프의 캐릭터 4인이 등장한다. 시각 요소는 전량 SVG/CSS 코드 생성으로, 외부 이미지 에셋이 0개다.

| 팀 | 캐릭터 | 역할 |
|---|---|---|
| 우리 팀 (청) | **플레이어** | 윷을 던지고 말을 옮기는 주인공 |
| 우리 팀 (청) | 까치 **"깍이"** | 아군 AI — 조언자 + 응원단장. 좋은 수를 훈수한다 |
| 상대 팀 (주황) | 호랑이 **"범발톱"** | 적 AI 리더 — 허세 가득한 메인 도발꾼 |
| 상대 팀 (주황) | 여우 **"꼬리아홉"** | 적 AI 참모 — 얄미운 계산가 |

## 게임 방법

- **목표**: 우리 팀 말 전부를 상대보다 먼저 완주시키면 승리
- **조작**: 클릭 2회 이내 — ① 윷 던지기 버튼 클릭 ② 이동할 말(칸) 클릭. AI 3인의 턴은 자동 진행
- **룰**: 표준 윷놀이 — 도(1)~모(5), 윷·모는 한 번 더 / 상대 말 잡으면 출발점으로 + 한 번 더 / 같은 팀 말은 업어서 함께 이동 / 모서리 칸에 서면 지름길 진입
- **종료**: 한 팀의 모든 말 완주 시 즉시 종료 → 결과 화면 (캐릭터들의 마무리 대사)

## AI 시스템 (핵심 셀링 포인트)

성격이 다른 **2-레이어 구조**다. 수를 두는 판단은 로컬 알고리즘이, 캐릭터 연기는 LLM이 맡으며, 어느 쪽이 실패해도 게임은 멈추지 않는다.

```
[판단 AI] 기대값 탐색 (로컬, 즉시)          — 게임 진행을 절대 블로킹하지 않음
[성격 AI] LLM 대사 + 캐릭터별 TTS (비동기)   — 실패·지연 시 프리셋 대사로 폴백
```

### 판단 AI — 봇의 수 선택 ([src/game/botAI.ts](src/game/botAI.ts))

LLM 없이 기대값 계산으로 동작한다. 가능한 수마다 아래 점수를 매겨 최고점을 고른다.

```
점수 = 내 진행 이득 + (상대 손실 + 잡기 추가턴 기대치) × aggression − 피격 기대 손실 × caution
```

- **피격 기대 손실**: 수를 둔 뒤 상대의 다음 던지기 확률분포(도~모, 이항분포)를 펼쳐, 각 결과에서 상대가 고를 최선의 잡기 손실의 기대값
- **캐릭터 성향 가중치**: 범발톱은 공격형(aggression 1.4 / caution 0.6), 꼬리아홉은 안전 주행형(0.9 / 1.4), 깍이는 균형형 — 플레이 스타일에 성격을 반영
- **승률로 개선 입증**: v1 휴리스틱 대비 v2 기대값 탐색이 선공 54.8% / 후공 54.3% (각 2000판 시뮬레이션)
- 깍이의 **훈수(HINT)** 도 같은 엔진 — 플레이어가 5초 이상 고민하면 기대값 탐색이 계산한 최선 수를 깍이 대사로 알려준다 (판단 AI × 성격 AI 결합 지점)

### 성격 AI — 캐릭터 대사·음성 (OpenAI, 서버리스 프록시 경유)

- **대사 생성** ([api/dialogue.ts](api/dialogue.ts)): 캐릭터 페르소나(시스템 프롬프트) + 판세 요약 + 직전 대사 최대 5개(티키타카) → `gpt-4o-mini`가 대사와 감정(emotion)을 JSON 스키마로 강제 생성. emotion은 SVG 캐릭터 표정과 연동. 페르소나 프롬프트는 서버 상수로만 보관해 클라이언트에서 조작 불가
- **음성** ([api/tts.ts](api/tts.ts)): 캐릭터별 고정 보이스 3종 + 톤 지시. 말풍선 타자기 효과가 음성 재생과 동기화되고, 발화 체인으로 대사가 끝나야 게임이 진행되는 엄격 동기를 유지
- **발화 타이밍**: 매 턴이 아니라 이벤트 순간(잡기·업기·윷/모·완주·역전·시작/종료)에만 발화 — 템포와 API 비용 관리
- **신뢰성 원칙**: 대사 3초 타임아웃 → 프리셋 폴백, TTS 5초 타임아웃 → 무음 스킵, 반복 대사는 세션 캐시로 재과금 차단, 프록시에 IP 레이트 리밋. **네트워크가 끊겨도 한 판이 완주된다**

## 실행 방법

브라우저에서 플레이 링크를 여는 것만으로 실행된다 (설치 불필요). 로컬 개발은:

```bash
npm install
npm run dev        # http://localhost:5173 — API 키 없이 프리셋 대사 폴백 모드로 동작
```

```bash
npm test           # 게임 룰·폴백 유닛 테스트 (Vitest)
npm run simulate   # 봇 vs 봇 자동 대전 시뮬레이션 (승률·분포 통계)
npm run build      # 프로덕션 빌드
```

LLM 대사·TTS까지 포함한 전체 동작은 Vercel 배포 환경에서 이뤄진다 (`OPENAI_API_KEY`는 서버 환경변수로만 보관, 클라이언트 노출 없음).
